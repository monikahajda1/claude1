# Zdjęcie → wektor do graweru laserowego

Plik `grawer.html` to gotowy program: otwórz go dwuklikiem w przeglądarce (Chrome, Edge, Firefox). Działa bez internetu, a zdjęcia nie są nigdzie wysyłane.

1. Wgraj zdjęcie.
2. Wybierz tryb: **Sylwetka** (czarno-biała), **Rysunek** (kontury) albo **Warstwy** (kilka odcieni, każdy w innym kolorze, czyli z inną mocą lasera).
3. Ustaw suwaki, patrząc na podgląd na tle sklejki.
4. Wpisz szerokość w mm i pobierz plik **SVG** (albo DXF), a potem otwórz go w LightBurn, LaserGRBL, xTool Creative Space itp.
