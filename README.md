# Grawer: zdjęcie → wektor do graweru laserowego

Aplikacja zamienia zdjęcie w plik **SVG** albo **DXF** do graweru w drewnie (np. w sklejce brzozowej).
Działa w przeglądarce i bez internetu. Zdjęcia nie są nigdzie wysyłane.

## Używanie
1. Wgraj zdjęcie.
2. Wybierz tryb: **Sylwetka**, **Rysunek** albo **Warstwy**.
3. Ustaw suwaki, patrząc na podgląd na tle sklejki.
4. Wpisz szerokość w mm i pobierz SVG albo DXF, a potem otwórz plik w LightBurn, LaserGRBL, xTool Creative Space itp.

## Instalacja jako aplikacja
Po opublikowaniu na GitHub Pages otwórz adres strony i:
- **Komputer (Chrome / Edge):** kliknij „Zainstaluj aplikację” albo ikonę instalacji w pasku adresu.
- **Android (Chrome):** menu ⋮ → „Zainstaluj aplikację” albo „Dodaj do ekranu głównego”.
- **iPhone / iPad (Safari):** przycisk Udostępnij → „Do ekranu początkowego”.

## Pliki
- `index.html`: cały program
- `manifest.webmanifest`, `sw.js`, `icons/`: instalacja i praca offline
